SIMORGH Desync integration

The native Desync engine is sourced from PingNG by ReZa Kh:
https://github.com/rezakhosh78/PingNG

The Android JNI entry point is adapted to the SIMORGH package namespace.
See the upstream repository for the complete source and licensing information.

Additional transport integrations sourced or adapted from PingNG:
- WARP account registration and WARP WireGuard/AWG configuration patterns.
- DNSTT Android client binary and argument contract.
- SoarDNS client source and runtime contract (Apache-2.0; see native/soar/LICENSE).
- AmneziaWG Go runtime and JNI surface (MIT; see licenses/AMNEZIAWG_GO_LICENSE.txt).
- DNSTT client distribution notice (see licenses/DNSTT_COPYING.txt).
